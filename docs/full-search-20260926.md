# 전남 요청 전체 검색·수집 기록 — 2026-09-26

## 방법

- 전라남도교육청 누리집(www.jge.go.kr) 통합검색의 첨부파일·게시판 결과를 `scripts/jge_site_search.py`로 조회했다. 이 검색은 띄어쓰기 없는 한국어 검색어를 거의 찾지 못하므로, 요청 파일명을 띄어 쓴 검색어로 다시 조회했다.
- 검색 결과 첨부명을 요청 파일명과 비교해 후보 게시물을 고르고, 연도가 다른 후보는 제외했다.
- 후보 게시물은 기존 수집기로 받았다(`data/jeonnam_search_jobs.json`). 게시물에 PDF가 없으면 `include_hwp` 옵션으로 HWP·HWPX 원본을 받았다.
- 웹 검색으로 찾은 교육부 게시물(특별교부금 기준, 학교폭력 사안처리 가이드북)과 전북 재게시 훈령도 받았다.
- 모든 파일의 SHA-256을 기존 71개 목록과 대조했고, PDF는 전 페이지 저해상도 렌더링, HWPX는 ZIP 무결성, HWP는 OLE 헤더를 확인했다.
