## 판본 판단

- 게시 연도는 2025(등록 2025.02.10)이고, 내용 판본은 교육부·평가원 ORM 2024-55를 전라남도교육청 발간등록번호로 재발간한 전남판이다.
- 앞서 회수한 A003(광주 게시, 202페이지, SHA-256 a249ac5a…)과 같은 ORM 2024-55 계열이지만 바이트가 다르고 페이지 수가 2쪽 많다. 두 파일의 쪽별 차이는 아직 비교하지 않았다.
- 원래 요청 대조표(160개)의 T001 파일명과 글자 단위로 대조하지 못했다. 이 세션에 인수인계 팩이 전달되지 않았기 때문이다.

## 검증 범위

게시물 선언 크기 일치, SHA-256 기록, pdfinfo·pypdf 파싱, 204페이지 전체 저해상도 렌더링(오류 0건), 표지·판권 확인까지 수행했다. 본문·표·각주 전수 검수, 재배포 허락 확인, MD 변환은 수행하지 않았다.

## 접속 환경

- 클라우드 작업 환경: www.jne.go.kr:443 연결이 수립 직후 끊김(curl 35, 재현 2회).
- 사용자 맥의 작업 셸(한국 회선): robots.txt 200, 게시물 301 → jge.go.kr 200, PDF 200.
- 따라서 전남 서버 전체 장애가 아니라 국외 실행 환경에서의 접속 제한일 가능성이 높다. 원인을 확정하지는 않는다.

## 수집기 수정

- 전남 게시판 첨부 선언 `wFileUpload.fileAttachAddTxt("이름.pdf","/upload/….pdf","크기")`를 추출하도록 추가했다. 이전 수집기는 이 형식을 읽지 못하고 게시물 자기 자신을 가리키는 「미리보기」 링크를 첨부로 오인했다(T001-page-1 not_a_complete_pdf).
- 게시물 자신을 가리키는 링크는 첨부 후보에서 제외한다.
- 게시물이 선언한 파일 크기를 하위 작업에 전달하고 `declared_bytes_match`로 기록한다.
- 사용자 폴더처럼 삭제가 막힌 위치를 출력 폴더로 쓰면 임시 파일 정리 단계에서 중단된다. 출력은 쓰기·삭제가 가능한 위치에 두고 결과만 복사한다.
- 오프라인 테스트 18개 통과(기존 16개 + 신규 2개). 수정된 추출 규칙을 저장한 실제 게시물 HTML에 적용해 첨부 1건과 선언 크기를 정확히 얻었다.
