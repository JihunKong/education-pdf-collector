# 게시판 크롤링과 Markdown 변환 (2026. 9. 26.)

## 게시판 크롤링

- `scripts/board_crawl/lister.py`와 `crawl.py`로 전라남도교육청 누리집 게시판 49곳의 목록을 읽었습니다. 게시판 목록은 `data/board_crawl/boards.json`에 있습니다. 목록 요청에는 `bbsId`가 필요합니다.
- 이렇게 모은 게시물은 9,165건(중복 제외 8,765건)입니다. 2023년 7월 이전 게시물만 남은 게시판에서는 목록 읽기를 멈췄습니다.
- `attscan.py`로 2024년 이후 게시물 2,428건을 열어 첨부파일명을 모두 모았습니다. 학교별 교육과정 문서, 유아교육 자료, 국외연수 게시판은 제외했습니다. 게시물 제목이 요청명과 달라도 첨부파일명으로 요청 문서를 찾기 위해서입니다.
- 이 단계에서 30개 파일을 새로 받았습니다. 받은 목록은 `data/board_crawl/*_jobs.json`에 있습니다. 새 파일 가운데 기존 71개나 앞서 받은 114개와 같은 바이트인 파일은 없습니다.
- 요청 160건의 판정은 다음과 같이 바뀌었습니다.

| 판정 | 이전 | 이후 |
|---|---:|---:|
| 대조 완료(공식 PDF 일치) | 50 | 50 |
| 원본 확보(HWP·HWPX, T041은 xlsm) | 26 | 39 |
| 후보(명칭·판 표기 차이) | 10 | 9 |
| 관련 자료만 | 8 | 18 |
| 미확보 | 66 | 44 |

- 다른 지역이나 다른 연도의 자료로 요청을 대체하지 않았습니다. T015(2024년 단체협약서)는 광주광역시교육청 체결본만 게시되어 있어서 「관련 자료만」으로 두었습니다. T039·T111은 다른 연도판만 있어서 「관련 자료만」으로 두었습니다.
- 수집기는 xlsm을 받지 않습니다. 그래서 T041 네비게이션 파일은 따로 내려받아 상태 파일에 기록했습니다.

## Markdown 변환

- 원문 파일 1개를 Markdown 파일 1개로 바꿉니다. 대상은 PDF 78개(8,068쪽), HWP 57개, HWPX 8개, XLSM 1개입니다.
- PDF는 `scripts/mdconv/convert.py`가 쪽 단위로 변환합니다. 글자 층이 있는 쪽은 pymupdf4llm(레이아웃 모드, OCR 끔)을 쓰고, 글자 층이 없는 쪽은 Tesseract 한국어 모델로 OCR합니다. 쪽마다 캐시에 저장하므로, 시간 제한 때문에 끊겨도 이어서 실행할 수 있습니다.
- Tesseract의 기본 페이지 분할(`--psm 3`)은 한국어 문서에서 가끔 쪽 전체를 잘못 읽었습니다. 표본 30쪽을 비교한 결과 `--psm 4`가 가장 안정적이어서 이 값을 씁니다.
- 글자 층은 있지만 글꼴 대응표가 깨진 PDF도 있었습니다(노무관리매뉴얼, 고교학점제 워크북 등). `badpages.py`와 U+FFFD 개수 검사로 이런 쪽 438개를 찾았고, 이 쪽들은 OCR 결과로 바꿨습니다. 최종 변환본에서 OCR로 추출한 쪽은 64개 파일의 2,090쪽입니다.
- HWP는 pyhwp의 `hwp5proc xml` 출력을, HWPX는 ZIP 안의 섹션 XML을 `hwpmd.py`로 읽습니다. 표는 Markdown 표로 쓰고, 셀 병합이나 중첩 표가 있으면 HTML 표로 씁니다. 1칸짜리 표는 인용 블록으로 씁니다. `hwp5html`과 `hwp5odt`는 몇 분이 지나도 끝나지 않아서 쓰지 않았습니다.
- `assemble.py`가 캐시를 합쳐 파일 머리에 YAML 정보(제목, 발행기관, 출처 게시물, SHA-256, 관련 요청과 판정, OCR 쪽 수, 공공누리 확인 안내)를 붙이고, 분류별 폴더와 `00_목록.md`를 만듭니다.
- 파일 이름은 macOS에서 잘리지 않도록 UTF-8 150바이트 안으로 줄입니다.
- 변환본과 원문은 이 공개 저장소에 올리지 않습니다. 공공누리 유형을 확인하지 않은 원문과 변환본은 재배포하지 않습니다.
