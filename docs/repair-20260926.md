## 결과의 범위

수집기의 반복 실패 처리와 부분 성공 판정을 수정했고, 새로운 PDF 7개를 실제로 회수했다. 전남교육청 서버의 외부 접속 문제나 원래 요청 160개의 전체 수집을 완료한 것은 아니다. 다른 지역·연도·전국 공통 문서를 전남 요청 판본의 대체본으로 계산하지 않았다.

## 측정한 장애

GitHub 실행 36212405593에서 www.jne.go.kr 게시물, 루트, robots.txt를 시험했다. DNS 조회는 완료됐지만 TCP 연결 시간은 0, TLS 연결 시간은 0, HTTP 상태는 0, 수신 바이트는 0이며 curl 종료 코드 28이었다. 기본 설정, IPv4, HTTP/1.1·TLS1.2 설정에서 모두 TCP 연결 단계 타임아웃이 발생했다.

실행 36212530047에서 jge.go.kr 및 hscredit.jne.go.kr도 같은 실행환경의 TCP 443 연결 실패를 보였다. 반면 cic.gen.go.kr와 moe.go.kr에서는 HTTPS 응답을 받았다. Jeonnam 학교 재게시 주소 두 개는 실행 36212772497에서 400 RequestBlocked 응답을 반환했다. 이 관측만으로 해외 IP 차단, 전체 사이트 장애 또는 이전 원인을 확정하지 않는다. 로그인·CAPTCHA·TLS 검증을 우회하지 않았다.

## 수정 내용

- 두 전남 URL만 요청하던 시험 코드 대신 JSON 목록을 처리하는 scripts/collect_batch.py를 추가했다.
- DNS·TCP 연결·TLS·읽기 오류와 HTTP 응답 오류를 구분하고, 연결 실패 또는 접근 제한이 발생한 호스트는 같은 실행에서 추가 요청을 보류한다.
- HTTP 성공 코드나 파일명만으로 완료 판정하지 않는다. PDF 헤더와 종료 표시를 확인하고 원본 바이트의 SHA-256을 기록한다. HTML 오류문은 PDF로 저장하지 않는다.
- 실제 HTML 링크와 페이지에 명시된 DEXT 첨부 PDF 경로를 추출한다. 알 수 없는 JavaScript 다운로드 주소를 추측하거나 실행하지 않는다.
- 파일별로 state.json을 저장한다. 동일한 로컬 출력 폴더를 유지하면 기존 파일의 해시를 확인해 건너뛰고, 손상된 파일만 다시 받는다.
- 새 GitHub 실행기는 이전 PDF와 상태를 자동 복원하지 않는다. 이 경우 결과 복원 또는 실패 항목만 담은 재시도 목록이 필요하다.
- 일부 실패·대기가 있으면 종료 코드 2와 partial 상태를 남기며, 성공한 원본과 실패 목록은 모두 보존한다.
- main 코드 변경 때 두 전남 URL을 다시 요청하던 이전 preflight 자동 실행을 폐기했다. 예약 실행은 등록하지 않았다.

## 남은 과제

전남에 대해서는 현재 접속 가능한 공식 경로를 추가 확인하거나, 정상 접속이 되는 사용자 로컬 환경에서 같은 수집기를 실행해 결과를 비교해야 한다. 사용자 크롬을 직접 조작한 적은 없으며 로컬 연결 성공은 아직 검증하지 않았다. 별도 전달한 맥 실행팩에는 전남 14개 및 전체 알려진 공식 출처 41개 목록과 원래 요청 파일명 160개 대조표가 있다. 160개 전체의 다운로드 URL이 해결됐다는 뜻은 아니다.

PDF 원문과 개인키는 공개 저장소에 커밋하지 않았다. 기존 수신 인증서를 유지하고 CI 결과는 암호화된 artifact로만 3일 보관한다. MD 본문 변환과 수강생 재배포는 수행하지 않았다. 교육부 늘봄학교 두 PDF의 원게시물은 출처표시·상업적 이용금지 조건을 표시한다. 나머지 자료의 문서별 이용조건은 검토 대기다.
